# 演出流程现状与方案入口

当前方案以 [小模型选择演出预设](ENSEMBLE_PRESETS_PROPOSAL.md) 为准。此前让剧本模型选择 face_* 或预设编号的建议已撤回。

剧本模型保持原接口：日中对白、原有台词切分、七类 emotion 和既有人物／镜头字段；不接收原始表情菜单，不输出新增 expression、嘴型或 preset_id。全篇修改和局部修改使用相同边界。

已有作品和手动微调的原始表情、保持动作信息继续兼容，但不会进入后续写作请求的结构字段。生产错误恢复、独立演出重试、有限自动重试、缓存、暂停及已完成场景沿用等修复继续保留。

现有素材清单继续保留 550 个保持姿态和 403 个独立表情条目，无保持循环的身体条目不进入审查清单。平静及非说话角色入镜的待机与保持段显示功能保留。

未来由小模型在剧本模型给定的七类情绪下，结合本幕对白、具体人物和上下文选择细分预设，再遵循出入镜、手动优先、旁观保持和动作连续性规则。预设建库及新选择器尚未执行。

不新增长发言内部的自动变化；继续沿用模型原有的台词切分，已有手动句内区间不改动。
